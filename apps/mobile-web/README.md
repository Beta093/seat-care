# 근로자 모바일 웹

휴대폰 비율의 독립 웹입니다. 네이티브 앱이 아니며, PC에서도 최대 폭 430px로 표시됩니다.

- 전용 화면: 내 상태 / 오늘 기록 / 기준 등록
- 관리자 메뉴 없음
- 실행: 저장소 루트에서 `npm run dev:mobile`
- 주소: http://127.0.0.1:4174
- 관리자와 동시 시연: 루트에서 `npm run dev`

시연 조작은 내 상태 화면 하단의 접힌 **시연 제어**에 있습니다. 위험 점수·체압·안내는 시연 데이터이며 실측이 아닙니다. API는 같은 origin의 `/api/state`, `/api/command`를 사용합니다. 원격 서비스 비밀키를 프론트엔드에 넣지 않습니다.
