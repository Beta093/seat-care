# 관리자 웹

데스크톱 모니터링용 독립 웹입니다.

- 전용 화면: 근로자 모니터링 / 조치 기록
- 근로자 내 상태 탭 및 압력 시연 조작 없음
- 실행: 저장소 루트에서 `npm run dev:admin`
- 주소: http://127.0.0.1:4173
- 근로자 모바일 웹과 동시 시연: 루트에서 `npm run dev`

시연 근로자 1명과 통합 관리 예시 2명을 구분합니다. 안내 확인은 경고를 해제하지 않으며, 모바일에서 압력이 해소되어야 회복으로 바뀝니다. 개발 서버 API의 화면별 명령 제한은 실제 사용자 인증·권한 시스템을 대체하지 않습니다.
