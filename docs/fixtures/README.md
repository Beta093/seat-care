# GUI 검증용 합성 기록

실제 사람·센서 측정이 아닌 **비개인 가상 데이터**다. 각 정상 파일은 61프레임, 18초다. 현재 사용자 서버에 요청하거나 기록을 수집해 만든 파일이 아니다.

| 파일 | 용도 | 기대 결과 |
| --- | --- | --- |
| legacy-v1-demo.json | 실제 보존된 v1 작성 코드로 생성 | 배치 미기록·지도 숨김, 숫자 보존 |
| adopted-v2-demo.json | 현재 v2 작성 코드로 생성 | 배치 ID 및 C1 중앙후방 지도 표시 |
| invalid-v2-layout-id.json | v2의 배치 ID를 이전 ID로 변경 | 파일 거부, 기존 정상 기록 유지 |
| invalid-v2-c1-position.json | v2의 C1 y를 0.50으로 변경 | 파일 거부, 기존 정상 기록 유지 |

v1의 0초/4.5초/9초/13.5초 점수는 각각 16/52/78/16이다. 모든 프레임의 시간·점수·경과 시간·5개 상대값을 자동 검사에서 원본과 비교한다. v1은 단순히 v2 헤더를 변경한 파일이 아니라 `seat-care-before-layout-v2`에 보존한 이전 작성 모듈의 실제 출력이다.

v2는 4.5초 오른쪽 분포, 9초 C1 중앙후방 분포, 13.5초 기준 분포 예시로 바뀐다. 파일은 기준·추정 결과 자체를 저장하지 않으며 현재 추정에 적용하지 않는다.

현재 사용자 기록이 있다면 먼저 저장한 뒤 **기기 → 시연 도구 → 시연 기록·파일 재생 → 기록 파일 열기**에서 선택한다. 기존 기록을 보존하지 않은 상태에서 새 기록 시작이나 화면 새로고침을 하지 않는다.

`provenance.json`에 합성 표시, 이전 작성 코드 SHA256 및 fixture 파일 SHA256을 보존했다. 재생성 명령은 `node tools/make-validation-fixtures.mjs <보존된 pre-layout-v2 프로젝트 경로>`다. 이전 프로젝트를 찾을 수 없으면 임의로 v2를 v1처럼 꾸며 재생성하지 않는다.
