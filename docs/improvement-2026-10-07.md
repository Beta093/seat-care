## 재현 문제 및 변경
1. 주의 예시(52점)에서 압력 누적을 시작하면 첫 0.1초에 40.19점으로 급락했다. 누적 시작 시 점수·센서값·시간을 보존하고 그 상태에서 증가하도록 변경. 회복 후 재누적도 연속적이다.
2. 자동 회복 중 75점에서 중지하면 회복 이벤트 없이 ‘개선·안정’ 표시가 나왔다. 중단 시 현재 점수의 상태로 돌아가고, 실제 회복 완료 이벤트가 있을 때만 개선 표시.
3. 기록 필터를 눌러도 aria-pressed와 선택 스타일이 갱신되지 않았다. 업데이트마다 선택 상태 동기화.
4. 기준 등록의 취소 버튼이 250ms마다 innerHTML로 교체되어 키보드 초점이 사라질 수 있었다. 고정 버튼을 유지하고 남은 시간 텍스트만 변경.
5. 근로자 화면에 본문 건너뛰기 링크와 페이지 이동 후 본문 초점 추가.
6. 두 화면에 시연 점수·시간·감소율이 의학적 안전 기준이나 치료 효과가 아니라는 표시 추가. 기존 센서 미연결/실측 0명 표기 유지.
7. 실제 로컬 HTTP 상태 공유 검증용 `tools/smoke.mjs` 추가. 이 스크립트는 실행 중인 시연 상태를 초기화하므로 별도 테스트 서버에서만 실행한다.
