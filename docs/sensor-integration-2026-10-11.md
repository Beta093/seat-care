## 진행 범위 변경: 웹을 열어둔 동안 알림

사용자 요청에 따라 현재 출시 대상으로 웹 전경 동작을 선택했습니다. 아래 네이티브 설명은 기존 구현 기록이며 앱 빌드·설치는 현재 필수 작업이 아닙니다.

- 웹 화면에 항상 접근 가능한 주의 배너, 사용자 동작으로 켜는 알림음, 선택적인 시스템 알림을 제공합니다.
- 알림 테스트는 시스템 권한을 요청하지 않습니다. 시스템 알림 미지원·거부·전송 실패 시에도 화면 안내는 먼저 표시됩니다.
- 시연도 같은 알림 경로를 사용하되 시연이라고 표시합니다. 실제 측정과 기록 저장소를 공유하지 않습니다.
- 숨겨진 문서에서는 판단·알림·기록 집계를 중지하고, 복귀하면 이전 연속 판단을 폐기해 새 수신값으로 다시 시작합니다. 방향별 1분 제한은 유지합니다.
- 기본 Android Chrome BLE 경로는 유지합니다. iPhone Safari에는 웹 BLE가 없어 현재 실제 센서 연결이 불가능합니다. 앱을 만들지 않는 iPhone 경로로는 센서 Wi-Fi/서버 중계가 추가로 필요하며, 이번 변경에서 구현한 것으로 표시하지 않습니다.
- 웹 화면 알림과 시스템 알림은 서로 다릅니다. iPhone 홈 화면 Web Push는 별도 푸시 구독·서버 전달 기능이므로 이번 화면 알림에 포함하지 않습니다.
- 네이티브 소스는 삭제하지 않고 보존합니다. 현재 빌드는 `npm run build`이며 `native:sync`는 필요하지 않습니다.

### 웹 사용 확인 순서

1. `npm run dev` → 기기 → 화면 알림 테스트. 권한 없이 배너가 나타나는지 확인.
2. 알림음 켜기 버튼으로 소리를 직접 활성화하고 기기 볼륨 확인.
3. Android Chrome HTTPS에서 BLE 연결 → 빈 방석/앉은 자세 보정 → 좌우 쏠림 3초 유지.
4. 기록·설정 페이지에서도 주의 배너 표시, 확인 버튼 동작, 같은 방향 1분 간격 확인.
5. 다른 탭으로 이동 후 복귀하여 이전 쏠림 시간으로 즉시 알림이 발생하지 않는지 확인.
6. 실제 기기가 없으면 분리된 시연 모드에서 동일한 흐름 확인. iPhone Safari에서는 현재 이 시연만 가능.

## 구조

- Vercel 정적 웹: 근로자 화면, 브라우저 BLE(지원 환경), 웹 Firebase 인증(구성 시), IndexedDB 기록.
- Capacitor Android: 같은 화면 + Java BLE foreground service. WebView가 쉬어도 서비스가 직접 수신/판정/알림/기록.
- Capacitor iOS: 같은 화면 + Swift Core Bluetooth central/background restoration. 알림은 UNUserNotificationCenter.
- 서버 푸시/FCM/APNs를 통한 원격 알림은 사용하지 않음. 근로자의 휴대폰이 판단하고 그 휴대폰에 로컬 알림을 띄움.
- iOS 웹 BLE 및 닫힌 웹에서 지속 감지는 지원하는 것으로 표시하지 않음.

## 의도적으로 보완한 부분

- 같은 방향 알림 제한을 방향별로 유지해 좌우 전환으로 반복 알림이 몰리지 않게 함.
- 2초 수신 공백 이후 3초 지속 조건을 다시 시작함.
- 경고 센서를 무시해도 자동 자세 경고는 계속 보류. 정상 재보정 후에만 다시 판단.
- Web Bluetooth 입력에는 유한·비음수·5채널·범위 검증 적용.
- 실제 입력은 시연 위험 점수와 혼합하지 않음.
- 웹의 7일 상세 기록은 작은 localStorage 대신 IndexedDB에 저장.
- 원본 Firebase 설정을 복사하지 않고 환경변수로 연결. 로그인과 동기화를 분리해 안내.

## 저장과 공백

웹은 실행된 1초 tick만 집계하며 중단된 시간을 소급해서 채우지 않습니다. Android는 서비스의 1초 tick을 사용합니다. iOS는 OS가 전달한 BLE 수신 이벤트의 초 단위 표본을 집계하므로 이벤트가 없거나 앱이 실행되지 않은 구간은 공백입니다. 타임랩스는 실제 기록 시각을 사용하고 긴 공백을 알린 뒤 이동합니다. 세 경로 모두 실제 센서 프레임을 만들어서 빈 시간을 채우지 않습니다.

로그인 계정 변경과 시연 전환 시 연결/기록 범위를 분리합니다. 브라우저 저장 공간 삭제 또는 앱 삭제 시 로컬 기록이 없어집니다. 네이티브 기록은 기기별이며 여러 직원이 기기를 공유할 때 계정별 기록 분리를 제공하지 않습니다.
