# 압력 패턴 변경·검증 기록 (2026-10-07)

## 변경

- 기존 가상 5점 배치와 시간 기반 점수를 확인하고, 점수와 독립적인 개인 기준 대비 분포 규칙을 추가했다.
- 10초간 유효하고 안정적인 연속 입력으로만 기준을 등록한다. 기준과 유사함을 바른 자세로 표시하지 않는다.
- 모바일 첫 화면과 관리자 상세에 분포 추정, 판단 불가 사유, 근거와 가상 출처를 표시한다. 모바일의 기존 요약/기록/기기 구조와 관리자 좌측 목록·우측 상세 배치를 유지한다.
- 원시 입력 계약, 오프라인 독립 관찰 라벨 데이터 검사와 재생 도구를 추가했다. 실제 하드웨어 입력 API는 구현하지 않았다.
- 기존 시연 점수와 관리자 확인 흐름은 별도로 유지한다. 보고서에는 현재 추정 스냅샷을 포함하며 기존 녹화 v1 재생은 추정을 재현하지 않는다.

## 확인된 검증

- npm test: 45개 통과. 기준 안정성/비대칭, 방향/경계, 누락·비정상·영값·포화·지연·역전·중복·오류, 출처/배치 변경, 반복 흐름/취소, 관찰 라벨과 개발/보류 분리 검증 포함.
- npm run check: 모든 JavaScript 구문 검사 통과.
- tools/pattern-smoke.mjs: 사용자/관리자 모듈 제공, 실제 10초 기준 수집, 방향 변화 시 기존 점수 독립성, 공유 상태, 잘못된 입력 보류·복구, 관리자 명령 제한 통과.
- tools/smoke.mjs: 기존 경고, 관리자 확인, 4초 회복 및 누적 흐름 보존 검사.

## 남은 검증과 결정

- 이번 실행 환경에 네이티브 CUA/브라우저 검증 도구가 노출되지 않아 변경된 화면의 직접 조작 및 360×640/390×740 캡처 검증은 완료하지 못했다. 이전 배치의 통과 기록을 이번 화면의 시각 검증으로 대체하지 않는다.
- 실제 FSR 모델/장착 위치/위아래 쿠션/영점·하중 보정/전송 계약 확정 및 전문가와 개인 기준·관찰 라벨 합의가 필요하다.
- 실측 0건. 정확도·의학적 효능·안전 시간은 미검증이다. 현재 결과는 미래 예측 모델이 아니라 관측 분포 규칙 추정이다.

## 보존과 적용

작업 시작 시 Desktop 원본을 seat-care-before-patterns에 보존했다. 전체 원본 SHA256 manifest가 일치하는 경우에만 변경 파일을 복사하고 바이트 단위로 확인한다. 패치는 작업공간 seat-care-patterns.patch에 보관한다. Notion, 다른 프로젝트 및 외부 서비스는 수정하지 않았다.

직접 사용 순서 및 알고리즘·라벨 계약은 pressure-patterns.md를 참고한다.

## 후속 브라우저 검증 접근 확인

지원 도구 전체 목록을 다시 확인했으나 Mac Safari/CUA/로컬 브라우저 제어 도구와 이를 활성화할 도구 검색 기능이 제공되지 않았다. 접근 권한 거절 오류가 발생한 것이 아니라, 호출할 수 있는 도구 자체가 없는 상태다. 원격 Firecrawl 브라우저는 사용자 Mac의 Safari가 아니므로 대체 검증하지 않았다. AppleScript, 별도 브라우저 드라이버, 접근성 권한 변경 등으로 우회하지 않았다.

다음은 **실제 브라우저에서 미검증**이다. 기존 엔진/API 검사 통과를 화면 검사 통과로 간주하지 않는다.

| 항목 | 기존 근거 | 브라우저 확인 상태 |
| --- | --- | --- |
| 미등록 판단 불가 → 10초 안정 기준 등록 | 엔진 테스트 및 원본 서버 API 통합 통과 | 두 화면 렌더링·직접 클릭 미검증 |
| 좌·우·앞·뒤 패턴 | 엔진 단위 검사 통과, 오른쪽 API 동기화 통과 | 각 방향의 두 화면 표시 미검증 |
| 누락·지연·모호한 경계 → 판단 불가 | 누락·지연 API 및 경계 엔진 검사 통과 | 문구·지도 숨김과 복구 표시 미검증 |
| 모바일 360×640 및 큰 글자 | CSS 반응형·큰 글자 규칙 구현 | 잘림·겹침·스크롤·첫 화면 배치 미검증 |
| 반복 클릭·취소 | 중복 기준 시작·취소 엔진 검사 통과 | 실제 버튼 상태와 클릭 경합 미검증 |
| 저장된 재생과 현재값 구분 | 기존 녹화/재생 엔진 검사, 표시 문구·현재 화면 숨김 구현 | 실제 모드 전환·복귀·포커스 미검증 |

알고리즘은 pressure-pattern-rules-v1 규칙 기반이며 학습 모델이나 미래 위험 예측이 아니다. 5채널의 앞 좌/우·뒤 좌/우·중앙은 시연용 배치 가정이다. 실제 물리 장착 좌표, 쿠션 위/아래 설치, 구체적인 센서 제조사·모델은 확정되지 않았다. coin 작업, Notion 및 다른 앱은 조작하지 않았다.
