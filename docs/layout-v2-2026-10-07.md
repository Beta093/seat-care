# 2026.10.07 채택 센서 배치 v2

근거는 사용자가 채택을 요청한 아이폰 미러링의 **Seat Care 특허 도면 초안 2026.10.07**이다. GUI 검증 작업에서 확대해 읽은 좌표를 전달받아 적용했다. 이번 구현 작업에서는 미러링·Safari를 직접 조작하지 않았다.

위에서 내려다본 모습이며 좌우는 **착석자의 좌우**, 위는 앞/무릎, 아래는 뒤/등받이다. 외곽 40×40의 좌상단 (0,0), x는 오른쪽, y는 아래다. **도면 단위는 확인 필요**이며 cm로 가정하지 않는다.

| ID | 위치 | 도면 중심 좌표 | 정규 좌표 |
| --- | --- | --- | --- |
| L1 | 왼쪽 앞 | (12,12) | (0.30,0.30) |
| R1 | 오른쪽 앞 | (28,12) | (0.70,0.30) |
| L2 | 왼쪽 뒤 | (13,27) | (0.325,0.675) |
| R2 | 오른쪽 뒤 | (27,27) | (0.675,0.675) |
| C1 | 중앙후방 | (20,34) | (0.50,0.85) |

C1은 정중앙이 아니다. 앞 두 점의 허벅지 아래 접촉 하중, 뒤 두 점의 둔부·좌골 주변 하중, C1의 중앙후방 접촉 하중은 **설계 관측 목표이며 검증된 측정 결과가 아니다.** 초기 중심 좌표와 개략 표시를 채택한 것이며 실물 제작·실장 검증·하중 보정·임상 검증 완료를 뜻하지 않는다.

GPIO는 모두 확인 필요다. 도면에는 숫자 채널 순서가 없다. 센서 제조사·모델·종류·감지면 크기·쿠션 위/아래 설치도 미확정이다. 코드에서 이 정보를 추측해 추가하지 않았다.

## 구현

- 배치 ID `seat-care-drawing-20261007-v2`, 규칙 버전 `pressure-pattern-rules-v2`.
- `layout.js`의 이름별 좌표가 지도 점, 보간, 추정 계산, 기록 메타데이터의 공통 기준이다. 지도는 40×40의 정규 비율을 유지하는 정사각형으로 표시하며 모바일 패널 구조는 유지했다.
- packet의 `channelIds`와 `values`를 쌍으로 매핑한다. 배열 순서를 바꿔도 같은 이름에 같은 값이면 같은 결과다. 내부 가상 직렬화 순서는 실제 하드웨어 채널/GPIO 순서가 아니다.
- 전체 5채널 상대값 T에 대해 X=Σ(value×x)/T, Y=Σ(value×y)/T를 계산한다. C1도 Y=0.85로 반영한다. 이는 **상대값 가중 중심**이며 센서 면적·하중 보정이 된 물리적 압력 중심이 아니다.
- X/Y의 개인 기준 대비 변화는 %폭/%깊이로 표시한다. C1의 전체 비중 변화는 %p로 표시하며 중앙후방으로 명명한다. 요약 좌우 비율은 L1/L2와 R1/R2의 외곽 4채널만 사용한다.
- 같은 배치의 새 기준을 10초 이상 등록해야 한다. 기준의 규칙 버전·배치 ID·좌표 서명이 다르면 판단을 보류하고 재등록을 안내한다. 기존 v1 기준을 승계하지 않는다.

## 규칙의 초기값

X/Y 변화 0.025 이내, C1 비중 변화 0.06 이내, 각 채널 비중 변화 0.08 이내면 개인 기준 유사다. X/Y 변화가 0.05 이상이면 해당 방향 이동이며 중간 구간은 판단 보류다. C1 비중 변화가 0.12 이상이고 좌우 중심 변화가 작으며 후방 좌표 이동 방향이 일치할 때 중앙후방 비중 증가/감소로 표시한다. 충돌하면 판단 불가다.

기준 수집 시 X/Y/C1 범위 0.035, 추정 안정 구간에서는 0.015를 사용한다. 10초·40프레임 기준, 1초·8프레임 추정 구간과 400ms 후보 유지, 입력 지연 1500ms 등의 품질 검사는 유지한다. 이 값들은 **공학적 시연 초기값**이며 새 좌표계에 맞춰 조정했지만 실측 정확도나 의료 안전 기준으로 검증하지 않았다.

## 이전 기록과 버전 경계

새 기록은 `seat-care-demo-recording` v2로 배치 ID, 이름별 좌표, 채널 ID 배열을 저장한다. 알려진 ID와 좌표가 모두 일치해야 지도 재생을 허용한다. 녹화 중 배치가 바뀌면 중단하고 이미 수집한 프레임을 보존한다. 기준·추정 결과 자체는 녹화하지 않으며 재생 데이터를 현재 추정에 주입하지 않는다.

v1 기록에는 배치 정보가 없다. 숫자 재생은 유지하지만 **배치 미기록·지도 숨김**을 표시한다. v1을 새 좌표로 재해석하거나 자동 변환하지 않는다. 알 수 없는 v2 배치 ID·중복 채널·좌표 변경은 거부한다. 실제 파일 다운로드/불러오기와 변경 후 화면 가독성은 GUI 재검증이 필요하다.

## 검증

단위 검사는 5개 좌표·지도 표시 위치·C1 후방 반영·이름별 순서 불변성·재등록·이전 기준 거부·기록 버전/좌표 경계·기존 Esc와 서버 기록 회귀를 포함한다. 격리 로컬 서버의 `node tools/layout-smoke.mjs`는 현재 4173/4174를 변경하지 않고 10초 기준 등록, 6개 패턴의 양쪽 API 동기화, 오류 보류, v2 기록, v1 지도 억제, 좌표 불일치 거부를 검사한다.

실물 센서 연동·장착 검증·임상 검증은 미완료다. 화면과 자료에 임상 정확도, 안전 시간, 치료 효과를 표시하지 않는다.


## 적용·검증 기록

테스트 66개와 전체 JavaScript 구문 검사 통과. 격리 서버에서 10초 새 기준, 6개 패턴 양쪽 API 동기화, C1 후방 반영, 오류 보류, 배치 메타데이터가 든 v2 기록 39프레임, v1 지도 억제, 변경된 좌표 거부를 확인했다. 시연 입력은 ID별 객체에서 직렬화하며 실제 배선 순서를 가정하지 않는다.

원본 적용 전 seat-care-before-layout-v2에 전체 파일을 백업하고 SHA256 manifest로 원본 변경을 확인한다. 서버 재시작 시 기존 메모리 기준을 승계하지 않으며 재등록 안내 상태로 시작한다. 이전 서버의 가상 상태는 별도 스냅샷으로 보존한다. 기존 브라우저의 기록/탭은 조작하거나 새로고침하지 않는다. 서버 메모리에만 남은 녹화 세션은 재시작 후 유지되지 않는다.

이번 변경의 360×640·큰 글자·5개 ID 표시·v1/v2 파일 재생 실제 화면은 별도 GUI 검증이 필요하다. 모바일의 기존 패널 구조와 차분한 색상은 유지했다. coin PID90721/세션45555와 다른 프로젝트·설정은 변경하지 않았다.
