# Seat Care

현재 배치는 **2026.10.07 채택 도면 v2**입니다. L1/R1/L2/R2/C1의 이름으로 매핑하며 C1은 중앙후방입니다. 배치 변경 후 기준을 새로 등록해야 합니다. 단위·GPIO·센서 종류/모델·감지면·쿠션 위/아래는 미확정입니다. [채택 좌표와 이전 기록 처리](docs/layout-v2-2026-10-07.md).

현재 첫 화면은 **개인 기준 대비 5채널 압력 패턴 추정**을 표시합니다. 기존 점수는 별도의 시간 기반 시연 지수입니다. 기준 등록과 방향·입력 오류 시연: [직접 시연 및 추정 규칙](docs/pressure-patterns.md).

근로자용 **모바일 비율 웹**과 관리자용 **데스크톱 웹**을 별도 프로젝트로 구성했습니다. 네이티브 앱이 아닙니다. 두 프로젝트를 npm workspace로 관리하며, 외부 패키지 없이 Node.js 22 이상에서 실행됩니다.

## 두 화면 함께 실행

```sh
npm run dev
```

- 근로자 모바일 웹: **http://127.0.0.1:4174**
- 관리자 웹: **http://127.0.0.1:4173**

근로자 화면에는 관리자 메뉴가 없고, 관리자 화면에는 근로자용 탭이나 시연 조작 버튼이 없습니다. 근로자 웹은 큰 모니터에서도 430px 이내로 유지됩니다. 각각의 HTML, CSS, JavaScript를 독립적으로 수정할 수 있습니다.

`npm run dev`로 실행한 두 서버는 하나의 시연 상태를 공유합니다. 모바일에서 압력을 누적하면 관리자가 같은 위험 점수와 경고를 확인할 수 있습니다. 관리자 확인 결과는 모바일 기록에도 나타납니다.

## 개별 실행

```sh
npm run dev:mobile
npm run dev:admin
```

위 명령은 각 웹만 독립 실행합니다. 별개 프로세스의 시연 상태는 공유되지 않으므로 **동시 시연에는 `npm run dev`를 사용**하세요. 전체 실행과 개별 실행을 동시에 시작하면 포트가 중복됩니다.

## 시연 방법

1. 모바일 **기기 → 기준 등록**을 눌러 10초 유지합니다.
2. 정상 상태에는 알림 배너가 표시되지 않습니다.
3. 모바일 **기기 → 시연 도구 → 시연 제어**를 펼쳐 **압력 누적 시작**을 누릅니다. 점수와 동일 압력 시간이 계속 올라갑니다.
4. 주의·경고가 발생하면 행동 안내와 관리자 상태를 확인합니다.
5. 관리자에서 **안내 확인**을 누르면 확인 기록이 두 화면에 반영됩니다.
6. 모바일에서 **체중 이동 · 압력 해소**를 누릅니다. 4초 동안 위험 점수가 내려가고, 타이머가 초기화되며 개선 기록이 생깁니다.
7. 모바일 **오늘 기록 → 하루 기록 예시**에서는 정상 → 주의 → 22% 개선 → 재주의 흐름을 별도로 볼 수 있습니다.

**전체 흐름 재생**은 기준 등록부터 회복까지 약 64초입니다. **상태 바로 보기**는 특정 상태를 빠르게 확인하는 예시 버튼입니다.

## 검증

```sh
npm run check

```

GitHub Actions도 같은 검사를 실행합니다. `.gitignore`에는 로컬 환경 파일, 로그, 임시 캡처가 포함되어 있습니다. 원격 저장소 생성이나 push는 수행하지 않았습니다.

## 구현 범위

이 저장소는 화면 및 **로컬 시연** 구현입니다. 실제 센서, 사용자 인증·권한, 영속 데이터베이스, 문자·푸시, 다중 기기 운영 서버는 연결하지 않았습니다. 실측은 0명이며, 시연 대상 1명과 관리자 통합 관리 예시 2명을 구분합니다.

시연 데이터는 서버 메모리에만 저장되며 서버 종료·시연 초기화 시 없어집니다. 새로고침해도 실행 중인 서버의 상태는 유지됩니다. 서버는 기본적으로 127.0.0.1에만 바인딩하므로 휴대폰이나 외부 네트워크로 공개되지 않습니다. 인증 없는 개발 서버를 운영 배포에 사용하지 마세요.

실제 센서 통신 규격이 결정되면 `packages/shared`의 상태 계약을 입력 어댑터에 연결해야 합니다. 위험 점수의 시연 임계값과 감소율은 의학적 판단 기준이나 실측 효과가 아닙니다. 명명된 5개 입력을 상대값으로 표시하고 절대 압력 단위는 사용하지 않습니다.

## 시연 보고서와 연결 오류

근로자 **오늘 기록** 또는 관리자 **조치 기록**에서 **시연 보고서 저장**을 누르면 현재 스냅샷과 최근 최대 200개 이벤트를 JSON으로 내려받습니다. 서버 종료/초기화 전에 저장하세요. 파일에는 가상 데이터임과 임상 효능을 증명하지 않는다는 제한이 포함됩니다. 하루 기록 예시는 내보내지 않습니다. Safari 다운로드 허용 여부에 따라 실제 저장은 브라우저에서 확인해야 합니다. 이 파일은 원시 센서 재생 파일이 아닙니다.

연결이 끊기면 현재 상태를 ‘확인 불가’로 표시하고 마지막 수신 시각을 보여줍니다. 남아 있는 수치는 마지막 수신값이며 명령 버튼은 비활성화됩니다. 연결이 복구되면 자동으로 최신 상태를 받습니다.

별도 테스트 서버에서 `node tools/smoke.mjs`를 실행하면 근로자/관리자 상태 공유를 검사합니다. 이 검사는 시연 상태를 초기화하므로 발표 중 실행하지 마세요.

추가 요구 대조 및 남은 검증: [Notion 요구 대조](docs/notion-requirements-2026-10-07.md).


## 가상 연속 기록과 파일 재생

근로자 **기기 → 시연 도구 → 시연 기록 · 파일 재생**에서 **새 기록 시작** → 시연 조작 → **기록 중지** → **기록 파일 저장** 순서로 사용합니다. 로컬 서버가 시작 이후 실제로 생성한 유효 가상 프레임(시연 점수·경과 시간·5채널 상대값)을 기록합니다. 관리자 탭을 보는 동안에도 서버 수집은 계속됩니다. 같은 수치라도 새 프레임이면 저장하며 오류 입력과 수신 공백은 채우지 않습니다. 최대 10분·2,401프레임이며, 새 기록은 이전 메모리 기록을 대체합니다. 서버 종료 전에 저장하세요. 브라우저를 새로고침하면 현재 기록에 접근하는 세션은 유지되지 않으므로 먼저 중지·저장하세요.

**기록 미리 재생** 또는 **기록 파일 열기**로 과거 가상 데이터를 표시합니다. 재생/일시정지, 위치 탐색, 좌우 화살표 5초 이동, Home/End, Esc 종료를 지원합니다. 재생 중 현재 상태 화면을 숨기고 ‘저장된 시연 재생’을 표시하며 관리자 상태에는 전달하지 않습니다. 종료 시 서버 상태를 다시 확인합니다.

파일은 `seat-care-demo-recording` v2 JSON, 최대 2 MiB입니다. 잘못된 형식·시간순서·채널 수·범위의 파일은 거부합니다. 파일 불러오기는 브라우저 내부에서 처리하며 서버로 업로드하지 않습니다. 새 기록 수집은 로컬 서버에서 수행합니다. 1.5초 넘게 기록이 없는 재생 구간은 값 대신 기록 공백을 표시합니다. 기존 이벤트 보고서 JSON은 재생 파일이 아닙니다. 이 기능은 **가상 연속 기록 재생**이며 실제 센서 원시 데이터 캡처는 아직 구현하지 않았습니다.

최종 구현·검증·남은 입력은 [최종 검증 보고서](docs/final-verification-2026-10-07.md)를 참고하세요. 앞선 날짜별 보고서는 해당 단계의 기록이며 최종 상태는 이 보고서를 우선합니다.


## 서비스 화면 구성 (2026-10-07 개편)

모바일 **요약**에 상태·점수·압력 분포·좌우 비율·집중 부위·지속 시간·행동 안내·최근 기록을 모았습니다. 360×640 및 390×740 CSS 화면에서 핵심 내용이 첫 화면에 보이도록 여백과 지도 크기를 조정합니다. 큰 글씨나 더 작은 화면에서는 잘라내지 않고 스크롤을 허용합니다.

하단 메뉴는 **요약 / 기록 / 기기**입니다. 기준 등록은 설정에, 가상 상태 조작과 기록·파일 재생은 설정의 시연 도구에 있습니다. 관리자 화면은 요약 → 필요한 조치 → 모니터링 대상·압력 분포 → 최근 활동 순서로 구성하며 추가 근로자 예시는 접어 둡니다.

[화면 개편 검증 기록](docs/service-layout-2026-10-07.md). 이번 개편은 사용 흐름과 UI 변경이며 실제 센서·인증·푸시 연결 범위는 기존과 같습니다.

사용자 선택에 따라 애플 건강 앱처럼 차분한 요약 화면으로 다시 구성했습니다. 점수와 압력 지도는 하나의 주요 영역에, 행동 안내와 최근 기록은 하단에 배치했습니다. 360×640 및 390×740에서 정상/경고와 큰 글씨를 확인했습니다.

관리자 배치 후속 개편: 왼쪽은 근로자 목록과 연결 요약, 오른쪽은 현재 근로자의 점수·압력 지도·집중 부위/시간·조치 안내입니다. 활동 기록과 전달 상태는 해당 근로자 상세 바로 아래에 배치했습니다.
