# 서비스 화면 구성 개편 — 2026-10-07

요청: 실제 서비스를 가정해 화면을 다시 구성하고, 특히 모바일 첫 화면에 웬만한 핵심 정보가 모두 보이도록 한다.

## 반영

- 홈: 날짜/제목, 시트 설정 진입, 현재 상태·시연 점수, 집중 부위·동일 압력 지속, 5점 보간 지도·좌우 비율, 행동 안내, 최근 기록, 의료 기준이 아닌 시연값임을 표시.
- 360×640처럼 짧은 화면에서는 날짜·중복 바로가기를 생략하고 여백과 지도를 줄인다. 해당 기능은 헤더 시트 링크와 하단 메뉴로 계속 접근 가능하다.
- 하단 메뉴: 홈 / 기록 / 설정. 상세 기록은 기록 화면, 10초 기준 등록과 취소는 설정으로 이동.
- 시연 제어·JSON 기록·파일 재생은 설정 → 시연 도구로 이동. 기능을 삭제하지 않고 홈에서 분리했다.
- 정상/주의/경고/해소/단절에 따라 상태와 행동 안내를 갱신한다. 해소 후 전후 점수와 상대 압력 감소율 표시를 유지했다.
- 관리자: 4개 요약 카드, 필요한 조치, 시연 근로자 표, 압력 지도·전달 상태, 최근 활동. 다른 근로자 예시 2명은 접힌 영역으로 이동. 정상일 때 불필요한 안내 확인 버튼을 숨긴다.
- 실제 센서 미연결·실측 0·시연 데이터 표시는 유지했다. 서비스가 실제로 개통됐다는 의미는 아니다.

## 검증

- 기존 27개 단위 테스트와 전체 JavaScript 구문 검사 통과.
- Safari에서 정확히 360×640, 390×740 CSS 크기의 로컬 iframe으로 정상/경고 화면을 육안 검사. 작은 화면에서 상태·점수·지도·집중 부위/시간·행동·최근 기록과 하단 메뉴가 한 화면에 보임을 확인했다.
- 360×640에서 큰 글씨 경고 화면도 줄바꿈이 유지되고 내용이 잘리지 않음을 확인했다. 이 검사는 실제 iOS 기기 검증을 대체하지 않는다.
- 설정 이동, 기준 등록 진행/취소, 시연 도구 이동 확인. 관리자 새 화면 정상 렌더링 확인.
- 기록·재생 데이터 규격과 상태 전이 엔진은 그대로 유지. 재생을 다른 경로에서 종료하면 숨겨진 버튼 대신 본문으로 초점을 돌리도록 보완.
- 더욱 작은 뷰포트나 사용자 확대에서는 접근성을 위해 스크롤을 허용한다. 높이를 고정하거나 overflow:hidden으로 내용을 잘라서 한 화면으로 보이게 만들지 않았다.

## 반영·복구

작업 루트의 `seat-care-before-service-redesign/`에 개편 전 전체 백업, `service-redesign-manifest.json`에 원본 해시를 보존했다. `seat-care-service-redesign.patch`에 변경 내용이 있으며, 전체 원본 해시가 일치할 때만 변경 파일을 바탕화면 프로젝트에 반영한다.

## 후속 시각 개편

사용자가 애플 건강처럼 차분하고 정돈된 방향을 선택했다. 모바일 CSS를 새로 정리하고, 점수·압력 지도·좌우 비율·핵심 지표를 하나의 영역으로 묶었다. 메뉴는 요약/기록/기기이며 시연 도구는 기기 안에 있다. 관리자도 배경·타이포·구획을 맞췄다. Safari의 360×640 및 390×740 iframe에서 정상/경고, 작은 화면 큰 글씨를 확인했다. 개편 전 백업은 `seat-care-before-layout-v3/`, 패치는 `seat-care-layout-v3.patch`다.

## 관리자 배치 후속 개편

상단의 큰 통계 카드와 별도 전폭 알림을 제거했다. 좌측 240px 근로자 목록/연결 요약과 우측 상세 영역으로 재구성했다. 우측에는 점수·분포 지도·집중 부위·시간 및 조치 확인을 함께 배치하고, 바로 아래에 활동 기록과 전달 상태를 두었다. 좁은 화면에서는 세로로 이어진다. Safari 정상/경고 화면, 안내 확인 후 미확인 경고 0·확인 완료·이벤트 추가, 조치 기록 이동을 검증했다. 원본 백업은 `seat-care-before-admin-layout/`, 패치는 `seat-care-admin-layout.patch`다. 모바일 파일은 변경하지 않았다.
