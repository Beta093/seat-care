# 배치 v2 후속 검증

새 기능을 추가하지 않고 남은 기록·버전 경계·모호 패턴을 검사했다. 원본 백업은 작업공간 `seat-care-before-v2-final-validation`이며 이번 작업에서 사용자 브라우저와 4173/4174 시연 상태는 변경하지 않았다.

## 완료한 자동 검증

`npm test`: **73개 통과**. `npm run check`: 전체 JavaScript 구문 검사 통과.

| 항목 | 확인한 근거 |
| --- | --- |
| 실제 이전 v1 기록 | 보존된 v1 작성 모듈로 61프레임 합성 파일 생성. 전체 프레임의 시간·점수·경과 시간·5개 상대값 일치 |
| v1 지도 숨김 | 실제 파일 열기·저장 처리 함수를 테스트용 DOM에 연결해 canvas 숨김, 지도 그리기 미호출, 버전 안내 확인 |
| v2 저장·재불러오기 | 실제 저장 처리의 Blob JSON을 다시 파일 열기 처리에 전달. 전체 숫자와 배치 ID·좌표·채널 매핑 일치 |
| 잘못된 배치 파일 | 이전 배치 ID 및 C1 y=0.50 파일 모두 거부. 이전에 불러온 정상 기록을 덮어쓰지 않음 |
| 재보정 경계 | 이전 배치에서는 새 기준 생성 불가. 새 배치로 전환 후 10초의 새로운 전체 구간이 있어야 등록. 이전 규칙/ID/좌표 서명의 기준은 미등록으로 표시 |
| 모호 패턴 | 유효한 ‘주의’ 분포가 기존 오른쪽 추정을 대체해 판단 불가로 표시. 양쪽 표시 컨텍스트에서 모호 사유와 변화량 유지, 기준 복귀 시 유사 분포로 회복 |

파일 처리 검사는 DOM·캔버스·다운로드 API를 테스트 대역으로 제공한다. 실제 Safari 레이아웃, 운영체제 파일 선택창, 다운로드 권한·실제 파일 저장까지 검증한 것으로 주장하지 않는다.

## 격리 통합 검사

실행 결과: 양쪽 API의 모호 분포 보류를 포함한 전체 검사 통과. 배치 v2가 포함된 45프레임 기록 생성·검증, v1 지도 억제와 좌표 불일치 거부를 확인했다.

`node tools/layout-smoke.mjs`는 OS가 배정한 별도 localhost 포트에서 자체 서버를 시작·종료한다. 사용자 4173/4174 서버와 사용자 데이터는 사용하지 않는다. 10초 기준 등록, 6개 패턴 양쪽 API 동기화, 유효하지만 모호한 분포의 판단 보류, 오류 입력 보류, v2 기록, v1 배치 미기록, 좌표 불일치 거부를 검사한다.

모호 분포 GUI 확인은 **정상 상태 바로 보기 → 새 기준 등록 → 주의 상태 바로 보기**로 재현할 수 있다. ‘주의’ 예시의 시간 기반 점수는 52다. 그러나 새 추정 규칙에서 X 이동은 약 4.37% 폭으로 2.5–5% 보류 구간이므로 패턴은 판단 불가여야 한다. 입력 자체는 유효하므로 지도를 숨기는 센서 오류와 구분한다. 새 시연 기능이나 임계값 변경은 추가하지 않았다.

## GUI 담당에게 전달할 파일과 남은 범위

`docs/fixtures/`의 [안내](fixtures/README.md)에 v1/v2 정상 파일 및 두 가지 거부용 파일을 제공했다. 모두 비개인 합성 데이터다.

이 작업공간과 전역 Node 패키지에서 Playwright/Puppeteer/jsdom 등 설치된 브라우저 테스트 패키지를 찾지 못했다. 무단 설치·보안 변경·Safari 동시 조작은 하지 않았다. **정확한 360×640 및 큰 글자 레이아웃, 실제 Safari 파일 저장/불러오기, 실제 화면의 지도 숨김과 모호 패턴 표시**는 별도 GUI 작업의 확인 결과와 합쳐야 한다.

실제 기기·의료·임상 검증은 여전히 미완료다. 규칙 임계값과 합성 기록 검사를 임상 정확도나 안전 시간의 근거로 사용하지 않는다. coin PID93268 및 다른 프로젝트는 조작하지 않았다.
